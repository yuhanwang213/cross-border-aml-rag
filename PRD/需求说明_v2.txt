资金出境与反洗钱合规问答助手 需求说明（v2，2026-09-30）

一、项目目标
构建一个面向个人和企业的合规问答知识库，回答“中国资金出境”和“反洗钱”相关的法律法规问题，并能根据用户描述的打算，评估其合规风险。

二、知识库范围
1. 法规依据：Regulations/Public 下的法律、行政法规、司法解释、部门规章、规范性文件（外汇管理、个人外汇、境外投资、携带现钞出入境、反洗钱、大额和可疑交易报告、客户尽职调查、刑法相关条文、虚拟货币等），以及 Regulations/Case 下的 3 件司法解释（洗钱、非法买卖外汇、帮助信息网络犯罪活动）。
2. 典型案例：Regulations/Case 及 Regulations/Public 中的典型案例文件（洗钱、非法买卖外汇、地下钱庄、非法集资等判罚案例），只作参考，不作为结论依据。文件按标题识别是否为案例，与所在文件夹无关。
3. Regulations/Internal 下的企业内部制度不入库。
4. 每份文件标注效力层级（法律 / 行政法规 / 司法解释 / 部门规章 / 规范性文件 / 典型案例）和发布日期；不同文件规定不一致时，如实列出并说明各自的适用范围；标注“已修改”的文件，回答时提醒用户核实现行版本。

三、功能需求
1. 法规问答：用户提问，系统检索相关条款后作答。
   - 第一句先给结论，一般不超过 400 字。
   - 每个结论必须标注出处，格式为“文档名 + 章 + 条”（PDF 文件可附页码）；出处由程序根据条款信息生成。
   - 知识库中找不到依据时，回答“知识库中没有相关规定”。
2. 案例展示：问题与案例相关时，在回答下方展示相关案例（最多 3 个），可展开查看关键词、基本案情、裁判结果和典型意义；与案例无关的问题不展示。场景评估中展示案例的门槛更高。
3. 场景评估：用户描述自己想做的事（如“我想……”“朋友让我……”“会不会违法”），系统自动识别（“我想问”“请问”等咨询用语不算）并：
   - 拆解成若干合规问题，分别匹配法规和案例；
   - 给出结论：合规可行 / 有条件可行 / 存在较高合规风险 / 违法或被禁止 / 依据不足；
   - 分节说明适用规定、手续与额度限制、风险与法律责任、合规建议，每条标注出处；
   - 遇到“原则上不得……特殊情况除外”的规定，先判断用户是否符合例外，不符合则按原则下结论；
   - 全文一般不超过 800 字。
4. 引用校验：由程序校验模型给出的引用（条款必须来自本次检索结果，引句必须能在原文中找到），不合格的引用自动剔除；全部不合格时让模型重试一次，仍无有效引用则拒答。
5. 界面：Streamlit 网页，支持普通问答和场景评估两种模式（可自动识别，也可手动切换），侧边栏按效力层级列出知识库文件。不再区分用户角色和权限。

四、评测
1. 评测集（eval/questions.yaml，32 题）：法规问答、案例触发、知识库外、场景评估四类，用于日常调优。
2. 独立检验集（eval/holdout.yaml）：由需求方编写的真实问法题目，只用于检验，不用于调参。
3. 指标：检索命中率、引用准确率、要点覆盖率、拒答正确率、误拒率、案例触发准确率、平均回答长度。
4. 每次评测生成网页版报告，逐题展示回答、引用和案例。
5. 调用大模型（DeepSeek）的评测由需求方本人运行。

五、技术方案
文档解析（PyMuPDF、python-docx、textutil、本地 OCR）→ 按条款切分 → bge-m3 向量检索 + 关键词检索 → bge-reranker-v2-m3 重排 → Chroma 向量库 → DeepSeek 生成（JSON 输出）→ 程序校验引用 → Streamlit 界面。
