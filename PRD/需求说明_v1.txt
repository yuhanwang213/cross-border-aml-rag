一、项目需求：合规制度知识库问答助手

用Regulation中Public与Internal中的资料作为知识库。
回答时必须附上原文出处和页码；找不到依据时明确回答“知识库中没有相关规定”，而不是编造。
做一个小评测集（比如30个问题），统计检索命中率和引用准确率。
加一个简单的权限演示：不同角色只能检索自己有权限的文档。

整体架构
文档 → 按条款切分 → 向量化 → 向量库（带权限标签）
                                    ↓
用户提问 + 角色 → 按权限过滤 → 检索 → 大模型生成（必须引用）→ 代码校验引用 → 输出

二、技术选型：

文档解析：PyMuPDF
向量化：BGE系列中文向量模型
向量库：Chroma
生成：DeepSeek API
界面：Streamlit，带角色切换

三、评测集（30题左右）
约20题正常问题：看能否检索到正确条款、引用是否准确
约5题知识库外的问题：看是否正确拒答
约5题越权问题：看权限是否生效

最后得到三个指标：检索命中率、引用准确率、拒答正确率。
